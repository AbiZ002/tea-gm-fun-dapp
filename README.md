
# GM & FUN DApp

Welcome to GM & FUN, a fun DApp where you can check in daily, track your streak, and see when your next "Tea Time" is.

## Features
- Daily check-in with GM count
- Streak tracker
- Countdown for the next tea time

## Getting Started
1. Clone this repository.
2. Open `index.html` in your browser to start interacting with the app.

Enjoy your tea time!
